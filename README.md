# Machine_Learning_Unsupervised_Fraud-Anomaly_Detection
Unsupervised Fraud/Anomaly Detection
The problem statement focuses on evaluating the effectiveness of unsupervised anomaly detection techniques in identifying fraudulent credit card transactions. Since fraudulent transactions make up a very small proportion of all transactions, detecting them is challenging due to the highly imbalanced nature of the dataset. The project aims to determine whether anomaly detection algorithms can identify unusual transaction patterns and assign higher anomaly scores to potentially fraudulent transactions without using fraud labels during the training process. The models will learn the normal behaviour of transactions and flag deviations from these patterns as potential anomalies. The actual fraud labels will be used only after prediction to evaluate how accurately the models identify fraudulent activities.

Dataset Link: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
